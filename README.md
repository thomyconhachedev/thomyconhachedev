## 💼 Proyecto Destacado

### [🚀 DevJobs](https://github.com/thomyconhachedev/DevJobs)

API REST para conectar **desarrolladores** con **empresas** tecnológicas: registro, publicación de ofertas y postulaciones con un clic.

| Detalle | Info |
|:--|:--|
| **Stack** | Java 21 · Spring Boot · Spring Data JPA · MySQL |
| **Seguridad** | Spring Security + JWT con roles (CANDIDATE, EMPLOYER, ADMIN) |
| **Extras** | Swagger UI · Validaciones · Manejo uniforme de errores |
| **Deploy** | Docker en AWS EC2 (app + base de datos en instancias separadas) |

**Highlights:**
- 🔐 Autenticación JWT con filtros y claims por rol
- 📄 Paginación y filtros (tecnología, modalidad, seniority, ubicación)
- 📊 Historial de cambios en cada postulación (máquina de estados)
- 🐳 Contenedorizado y desplegado en la nube
